MCP server

A read-only MCP server,built right in.

Rowhouse bundles rowhouse-mcp as a sidecar. It shares your connections, so an assistant explores your real data — safely.

list_connectionsSaved connections visible to MCP
list_tablesTables & views
describe_tableColumns, types, nullability, defaults, PK
sample_rowsFirst N rows of a table
run_queryRead-only SQL; reads for Redis, find/aggregate for MongoDB
execute_sqlA write — only after you approve it in Rowhouse

Safe by construction

  • Every query passes a keyword guard and runs in a read-only transaction.
  • Writes always wait for your approval; destructive ones need the table name typed.
  • Only profiles you mark “Expose to AI” are visible.

Point any MCP client (Claude Desktop, Cursor, …) at the bundled binary:

{ "mcpServers": { "rowhouse": {
    "command": "/path/to/rowhouse-mcp"
} } }
FAQ

Questions,answered.

Rowhouse is free, open and compact. If something isn't covered here, open an issue on GitHub.

Is Rowhouse really free?

Yes. The client is MIT-licensed and free — no tab limits, no connection limits. You can build it yourself and use it commercially.

What does the AI see?

Only the schema (names and types) and the SQL you wrote. Rows never leave your machine. Bring your own model — any OpenAI-compatible API (OpenAI, OpenRouter, Ollama, LM Studio) or Anthropic.

How does the MCP server stay safe?

Reads pass a keyword guard and run inside a read-only transaction (BEGIN READ ONLY on Postgres, START TRANSACTION READ ONLY on MySQL, PRAGMA query_only on SQLite). Writes always wait for your approval in the app.

Why does macOS say the app can't be opened?

The builds aren't code-signed yet. Right-click the app and choose Open once, or run xattr -dr com.apple.quarantine /Applications/Rowhouse.app.

Which platforms are supported?

macOS (universal — Apple silicon & Intel), Windows (x64) and Linux (AppImage, .deb, .rpm). Installers for all three are built on every release.

Which databases work today?

Postgres, MySQL/MariaDB, SQLite, DuckDB, ClickHouse, Redis, Neon, Supabase, Turso/libSQL and Cloudflare D1 are integration-tested. SQL Server, MongoDB, Cassandra/ScyllaDB and more are in beta. See the full list.
