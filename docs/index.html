Workflow

Built for people who live in a query editor.

Compact, keyboard-first, and quick enough to disappear. No Electron bloat — a native Tauri shell over a Rust engine.

Dialect-aware SQL editor

CodeMirror 6 with syntax highlighting, table autocomplete, and multi-statement scripts. ⌘↵ runs the selection or the whole file into separate result sets.

-- runs as one script, two result sets
SELECT count(*) FROM orders; SELECT now();

Virtualized result grid

Sort, resize and keyboard-navigate huge sets. JSON, booleans and numbers stay typed; ⌘C copies any cell. NUMERIC keeps full precision.

Secrets in the keychain

Passwords live in Keychain or Credential Manager, never in a config file. Profiles are plain JSON.

Read-only mode & tags

Flag a connection red for production and lock it to reads — guarded twice over.

Command palette

Jump to any connection, table or action with ⌘K. Light and dark, motion under 160ms.

Schema at a glance

Filterable tree of tables and views, with Data and Structure views per table.

rowhouse-mcp

Safe, read-only eyes on your data — for any AI assistant.

A stdio MCP server ships in the box. It reads the same connections as the app and exposes only the profiles you opt in, so an assistant can answer questions about real data without ever touching it.

list_connectionsConnections you've exposed to MCP
list_tablesTables and views in a connection
describe_tableColumns, types, nullability, defaults, PK
sample_rowsThe first N rows of a table
run_queryRead-only SQL — SELECT / WITH / SHOW / EXPLAIN

Keyword guard

A conservative classifier rejects anything that isn't a plain read before it ever reaches the database.

Read-only transaction

Every query runs inside BEGIN READ ONLY, START TRANSACTION READ ONLY, or PRAGMA query_only.

Opt-in per connection

Only profiles you explicitly mark are visible to MCP. Everything else stays invisible to the assistant.
